What this tool is

Pixel Raconte Publisher is a private, internal script used by one independent creator to schedule short educational videos on their own three YouTube channels (Pixel Raconte, Curio Box and Orbopolis). It is not offered to the public, has no user accounts and no other users.

YouTube API Services

This tool uses YouTube API Services to upload videos, set their title, description, thumbnail and scheduled publication date, and to read basic statistics of these same channels (views, likes, comments, retention). By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed and stored

  • OAuth refresh tokens for the creator's own channels, stored only on the creator's computer, never shared.
  • Metadata and statistics of the creator's own videos, including private YouTube Analytics data of these channels (retention, traffic sources), stored in a local database on that computer to follow their performance.

The tool does not access, collect or store any data about viewers or other YouTube users. No data is sold, shared with third parties or used for advertising.

Retention and deletion

Statistics are kept as long as the channels are active. Access can be revoked at any time from the Google security settings page; the local tokens and data are then deleted from the computer on request.
